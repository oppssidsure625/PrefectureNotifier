# 都道府県越境通知 (PrefectureNotifier)

移動中に都道府県の境界を越えると、東北ずん子が音声と振動でお知らせしてくれるAndroidアプリです。  
県境を越えるドライブのお供に最適です。  
私の使用しているカーナビにはこの通知が無くて寂しかったので作りました。

## 特徴
- **バックグラウンド動作**: Foreground Serviceにより、アプリを閉じていても動作し続けます。  
  停止時は通知バーから停止するか、"監視を停止する" をタップしてください。
- **ずん子ボイス**: 「〇〇県に入りました」と、越えた瞬間にボイスでお知らせ。  
  5秒に1回、座標を確認しています。
- **ダークモード対応**: システム設定に合わせたUIカラーの自動切り替え。
- **音量調整**: 同じ携帯から音楽を流しつつ使用するために、別で音量を絞れるようにしています。
